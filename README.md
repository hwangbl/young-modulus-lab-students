# 杨氏模量交互实验室 · 学生公开版

发布后的学生入口：<https://hwangbl.github.io/young-modulus-lab-students/>。

无需 GitHub 账号或课程密码，即可预习实验、操作动态光杠杆、认识真实仪器、练习实验步骤，并处理实验数据。本仓库和发布网页均不包含课件文件，也不提供课件下载。

学习进度和录入的数据保存在当前浏览器，可导出实验数据 CSV 或打印实验报告。所有演示数据均有模拟标识，不能作为实际测量结果。

首次发布：仓库所有者进入 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存。学生入口在 GitHub Pages 发布成功后生效。
