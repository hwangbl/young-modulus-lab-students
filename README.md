# 杨氏模量交互实验室 · 学生公开版

发布后的学生入口：<https://hwangbl.github.io/young-modulus-lab-students/>。

无需 GitHub 账号或课程密码，即可预习实验、操作动态光杠杆、认识真实仪器、练习实验步骤，并处理实验数据。本仓库和发布网页均不包含课件文件，也不提供课件下载。

数据处理支持下载 CSV 填写模板、导入实验记录、自动评估不确定度、均值点线性拟合，并导出 PNG / SVG 图像、CSV 报告或打印实验报告。学习进度和录入的数据只保存在当前浏览器；导入文件也仅在本机读取。所有演示数据均有模拟标识，不能作为实际测量结果。

误差限按课程条件自动建议，并支持手动修改或恢复建议。L、D 的仪器误差限分别随测量值计算，估读误差分别评估。原始标尺读数记录到 0.1 mm，均值的显示位数与两读数之和一致；误差及不确定度显示支持 1–2 位有效数字。

有效数字运算规则图片可放大查看。每次填入演示数据前，须输入任课教师提供的演示验证码；取消或验证未通过时保留当前实验记录。

使用数据导入时，先进入“数据处理”下载模板，在电子表格软件中按模板中的单位填写原始读数与误差限，另存为 UTF-8 CSV，再回到网页导入。请保留字段和记录次序。课程课件文件不随网页提供。

首次发布：仓库所有者进入 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 /(root)，保存。学生入口在 GitHub Pages 发布成功后生效。
